# WPC Terasztervező – demó

Interaktív, szemléltető demó egy WPC teraszburkolat-tervezőhöz: alakzat és méretek, LUX/SAFETY rendszer és szín, deszka- és párnafa-kiosztás, szegélyprofilok, szintezőtalpak, anyagszükséglet, szabási jegyzék és 3D nézet.

Egyetlen önálló `index.html`, build nélkül fut. A 3D nézethez a three.js a jsDelivr CDN-ről töltődik.

A demó tájékoztató jellegű, nem végleges termék.
